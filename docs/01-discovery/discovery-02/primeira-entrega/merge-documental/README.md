A primeira entrega dá continuidade ao entendimento de uma atividade entre pessoas, repositórios e agentes. A R04 registra as decisões sobre essa entrega. Os catálogos de onboarding, memória e documentação visual acrescentam comportamentos e cenários de avaliação com o grau de decisão registrado em cada tema. Esta edição é uma proposta documental de S1-MERGE-EA-20261122-01.
