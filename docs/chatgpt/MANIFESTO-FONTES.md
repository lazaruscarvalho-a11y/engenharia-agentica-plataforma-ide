O manifesto do pacote identifica commit imutável, caminhos, tamanhos, hashes e mapa de projeção. Os documentos indispensáveis permanecem integralmente disponíveis; links a Git não substituem seu conteúdo nas Fontes. Não carregar scripts, segredos, código corporativo, transcrições reais, respostas de ensaios, gabaritos ou relatórios de gates como instruções do Discovery. Materiais da avaliação PM-R5 não constituem pendências atuais de produto.

As Instruções são o texto separado [INSTRUCOES-PERMANENTES.md](INSTRUCOES-PERMANENTES.md). O procedimento de aplicação está em [CONFIGURACAO.md](CONFIGURACAO.md). Fontes são snapshots: publicação no Git não as atualiza automaticamente. A aplicação só é comprovada depois de inventário, download e comparação dos cinco objetos nativos e releitura integral do campo de Instruções.
