# Plataforma/IDE de Engenharia de Software Agêntica

A plataforma pretende ligar intenção, conhecimento de engenharia, requisitos e evidências ao longo do ciclo de trabalho. A primeira entrega em discovery é o Motor de Engenharia Agêntica para Devin Web, CLI e Desktop e Claude Code. A IDE completa depende de especificação, validação e aprovações próprias.
